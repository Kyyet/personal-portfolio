# Personal Portfolio

Personal portfolio website for **Luky Virya** — Software Engineering graduate & Web Developer. Showcases profile, education, certificates, experience, projects, and skills.

Modern dark theme with a deep charcoal background (`#0A0A0A`) and electric blue accent (`#005EE9`).

## Tech Stack

- **[Vite](https://vite.dev/)** — build tool & dev server
- **[Tailwind CSS v4](https://tailwindcss.com/)** — styling & design tokens
- **Vanilla JavaScript** — no framework, fast and lightweight
- **Plus Jakarta Sans + JetBrains Mono** — typography

## Features

- Sticky navbar with blur-on-scroll and active section indicator
- Hero with staggered entrance animation, grid pattern, and subtle glows
- About, Education (timeline), Certificates (cards + lightbox modal), Experience (timeline), Featured Projects (3-column responsive grid)
- Skills grouped by category + horizontal tech marquee
- Contact section with validation-friendly form
- Fully responsive (desktop / tablet / mobile), semantic HTML, keyboard-friendly, `prefers-reduced-motion` support

## Getting Started

```bash
npm install
npm run dev      # start dev server → http://localhost:5173
npm run build    # production build → dist/
npm run preview  # preview the production build
```
